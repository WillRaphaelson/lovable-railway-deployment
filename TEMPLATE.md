# Deploy and Host Lovable Deployment Examples with Railway

Deploy two small Launchpad apps that demonstrate the hosting paths used by newer TanStack Start and older React + Vite Lovable projects. These are purpose-built samples, not exports of a Lovable workspace.

## About Hosting Lovable Deployment Examples

The template creates two independent web services from one public repository. The server example uses Lovable's build configuration package and Nitro. The static example uses React + Vite and Railpack's static site serving. Both include a nested route for deployment checks.

## Why Deploy Lovable Deployment Examples on Railway?

Inspect a working server deployment and static deployment in one project, then apply the matching configuration to your own app. Public domains, build logs, and service configuration are available in Railway.

## Common Use Cases

- Learn which deployment path matches your Lovable app.
- Test nested-route handling and request-time server execution.
- Explore a small Railway project before importing your own repository.

## Dependencies for Lovable Deployment Examples

The template uses public GitHub sources and requires no external accounts or secrets. Both services consume Railway resources and count toward your usage. Stop them when you finish exploring.

### Deployment Dependencies

Node.js 22; React; Vite; TanStack Start; Lovable Vite configuration; Nitro; Railway Railpack. No database, authentication, storage, or backend migration is included. For the full app source and local instructions, see the repository README.
